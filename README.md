# with-ai

폰에서 프로젝트 계획과 작업 진행 상황을 기록하고, 코드 제작 AI에 전달할 요청문을 준비하는 한국어 웹앱입니다.

## 실행

Node.js 22 LTS 이상과 npm을 사용하세요. 환경 변수나 API 키는 필요하지 않습니다.

```bash
npm ci
npm run dev
```

브라우저에서 <http://localhost:3000>을 엽니다.

프로덕션 실행:

```bash
npm run build
npm start
```

## 구현 기능

- 프로젝트 생성·수정·삭제, 삭제 확인, 첫 사용 안내
- 작업 카드 생성·수정·삭제 및 제목·설명·요구사항·완료 조건·상태·생성/수정 시각 저장
- 상태 이름과 색상을 함께 표시하고 상태별 카드 개수를 표시하는 필터
- 카드 상세에서 직접 작성하는 최신 진행 메모: 한 일, 막힌 점, 다음 할 일, 메모 수정 시각
- 완료 개수 / 계산 대상 개수와 진행률 표시
- 프로젝트와 카드 정보를 텍스트 양식에 넣는 AI 작업 요청문 생성·편집·복사
- 복사 성공/실패 안내, 실패 시 자동 전체 선택과 직접 복사 안내
- JSON 내보내기 및 형식 검증·교체 확인을 거치는 가져오기
- 모바일 세로 카드 목록과 하단 주요 작업 버튼, PC 프로젝트 사이드바
- 입력 이름·필수 값 오류 표시, 키보드 포커스, 네이티브 모달과 화면 읽기 안내
- 저장 공간/권한 오류 안내 및 실패한 입력 유지, 손상 데이터의 원본을 유지하고 백업 복구 안내

### 작업 상태

| 상태          | 색상   | 의미                                        | 진행률 포함 |
| ------------- | ------ | ------------------------------------------- | ----------- |
| 할 일         | 회색   | 앞으로 시작할 작업                          | 포함        |
| 진행 중       | 노란색 | 현재 진행하는 작업                          | 포함        |
| 완료          | 초록색 | 완료 조건을 충족한 작업                     | 포함        |
| 안 할 거      | 검은색 | 이번 프로젝트에서는 진행하지 않기로 한 작업 | 제외        |
| 폐기 아이디어 | 빨간색 | 검토 후 아이디어 자체를 폐기한 작업         | 제외        |

진행률은 `완료 ÷ (할 일 + 진행 중 + 완료) × 100`이며 표시할 때 정수로 반올림합니다. 계산 대상이 0개이면 0%입니다. 검은색 카드에는 밝은 글자를 사용합니다.

## 저장 방식과 한계

- 로그인과 서버 저장 없이 `localStorage`의 `with-ai:data:v1`에 버전 1 데이터를 저장합니다.
- 저장은 명시적인 저장 버튼을 눌렀을 때 이루어집니다. 카드 정보와 진행 메모는 별도로 저장합니다. 저장하지 않은 입력과 요청문 편집 내용은 닫기/새로고침 시 유지되지 않습니다.
- 진행 메모는 카드마다 최신 1개만 보관합니다. 메모를 먼저 저장한 후 AI 요청문에 반영할 수 있습니다.
- 데이터는 **현재 기기·브라우저·사이트 주소에만** 존재합니다. 다른 브라우저나 기기, 개발 서버와 배포 사이트 사이에 자동 동기화되지 않습니다.
- 브라우저 데이터 삭제, 시크릿 창 종료, 저장소 정리 등으로 기록이 사라질 수 있습니다. 중요한 기록은 JSON으로 백업하세요.
- 브라우저 저장 공간이 부족하거나 저장 권한이 차단되면 저장에 실패할 수 있습니다. 실패한 저장은 성공으로 표시하지 않으며 편집 화면을 유지합니다.
- 같은 사이트의 다른 탭에서 바뀐 데이터는 `storage` 이벤트로 갱신합니다. 아직 읽지 않은 외부 변경을 발견하면 저장을 중단하고 다시 시도하도록 안내합니다. 동시 편집 병합 기능은 없습니다.
- 복사 기능은 HTTPS 또는 localhost 및 브라우저 클립보드 권한이 필요할 수 있습니다. 실패 시 선택된 텍스트를 길게 누르거나 Ctrl+C / ⌘C로 직접 복사할 수 있습니다.

### JSON 백업

설정의 **JSON 내보내기**에서 모든 프로젝트·카드·메모를 내려받습니다. **JSON 가져오기**는 파일을 읽고 버전·필드 타입·필수 이름·상태·날짜·중복 ID를 검증한 뒤 교체할 프로젝트와 카드 개수를 안내합니다. **데이터 교체**를 눌러야 기존 데이터를 모두 교체합니다. 잘못된 파일과 취소는 기존 데이터를 변경하지 않습니다.

가져오기 제한: 최대 5MB, 프로젝트 1,000개, 전체 카드 10,000개. 프로젝트 이름은 100자, 카드 제목은 120자, 설명·요구사항·완료 조건·각 메모는 10,000자까지입니다. 알 수 없는 추가 필드는 가져올 때 생략합니다. JSON 파일에는 사용자가 쓴 내용이 포함되므로 파일 보관 위치를 직접 관리하세요.

## 기술과 구조

Next.js App Router 16 / React 19 / TypeScript / Tailwind CSS 4 / Lucide 아이콘. Tailwind의 기본 스타일과 접근성 유틸리티 위에 전역 CSS로 화면을 구성합니다.

| 경로                           | 역할                                            |
| ------------------------------ | ----------------------------------------------- |
| `src/app`                      | 페이지, 루트 레이아웃, 반응형 스타일            |
| `src/components/workspace.tsx` | 프로젝트 선택, 카드 목록, 집계, 설정·백업 흐름  |
| `src/components/forms.tsx`     | 프로젝트/카드 입력, 카드 상세·메모, 요청문 편집 |
| `src/components/dialog.tsx`    | 네이티브 모달과 포커스 관리                     |
| `src/lib/model.ts`             | 타입, 상태, 집계, 요청문 양식, 백업 검증        |
| `src/lib/store.ts`             | 브라우저 저장, 갱신 구독, 오류 처리             |
| `tests`                        | 모델 단위 테스트 및 모바일/PC 브라우저 테스트   |

`AGENTS.md` / `CLAUDE.md`에는 Next.js 개발 서버가 생성하는 프레임워크 작업 지침이 있습니다. 해당 Next.js 버전의 가이드는 `node_modules/next/dist/docs`에서 확인할 수 있습니다.

```bash
npm run typecheck
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```
